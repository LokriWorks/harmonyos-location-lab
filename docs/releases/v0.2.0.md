鸿蒙位置实验室的第一个 Windows 图形界面版本。

## 下载哪个文件？

- **HarmonyOSLocationLab-v0.2.0-win-x64.exe**：Windows x64 用户下载此文件，双击使用，无需安装 Python。
- **HarmonyOSLocationLab-v0.2.0-licenses.zip**：随附依赖许可，供查阅。
- **SHA256SUMS.txt**：下载文件的 SHA256 校验值。
- GitHub 自动生成的 Source code：开发者使用的源码。

## 使用

双击 EXE → 选择官方 HDC 的 hdc.exe → 检测设备 → 输入 WGS84 坐标或导入 GPX → 设置时长与间隔 → 开始测试。

HDC 需从华为官方开发工具另行获取，不在 EXE 内；保留 HDC 同目录 DLL。手机需要开启 USB 调试并授权。未连接手机也可以导出 GPX。

支持停止与恢复，正常关闭时尝试清理；断线时恢复可能失败，恢复连接后重试，并在手机上确认正常定位。不要强行结束运行中的程序。

## 验证范围

已完成无设备单元测试和移除 Python PATH 后的 EXE 离线启动、界面工作线程、取消和清理测试。尚未重新完成本版真机回归。

历史鸿蒙 7.0.0 环境中微信“发送位置”预览多次显示模拟位置；校园跑小程序测试失败，连续移动尚未稳定验证。不把历史结果扩大成所有同版本设备的兼容承诺。
