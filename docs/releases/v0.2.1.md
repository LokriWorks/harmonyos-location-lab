# v0.2.1 中文修复与入门教程

修复 v0.2.0 上传时的中文编码损坏，重新发布 Windows x64 EXE。请使用本版替换旧 EXE；旧版中的部分中文文档和界面文字有误。

## 下载与使用

1. 下载 **HarmonyOSLocationLab-v0.2.1-win-x64.exe**，双击打开，不用安装 Python。
2. 选择你电脑上官方 HDC 工具里的 `hdc.exe`，保留它旁边的 DLL；本 EXE 不含 HDC。
3. 用支持数据传输的 **USB 数据线** 连接手机和电脑，开启手机 USB 调试，解锁手机并允许电脑调试。
4. 点击 **检测设备**，确认状态为 **Connected**。
5. 输入固定坐标或导入 GPX，设置时长和点间隔，点击 **开始测试**。
6. 保持 USB 连接；结束时点 **停止并恢复定位**，并在手机上确认恢复后再拔线。
