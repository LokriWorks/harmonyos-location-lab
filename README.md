# 鸿蒙位置实验室

[![Tests](https://github.com/zoe2026test/harmonyos-location-lab/actions/workflows/test.yml/badge.svg)](https://github.com/zoe2026test/harmonyos-location-lab/actions/workflows/test.yml)
[![Download](https://img.shields.io/badge/Windows-Download_EXE-176b8c)](https://github.com/zoe2026test/harmonyos-location-lab/releases/latest)
[![MIT](https://img.shields.io/badge/license-MIT-147d75)](LICENSE)

在 Windows 电脑上设置坐标，通过 HDC 调试工具提交到连接的鸿蒙手机。支持固定位置和导入 GPX 轨迹。

**实际修改手机位置时，必须用支持数据传输的 USB 数据线连接手机和电脑，并在手机上开启 USB 调试、允许电脑调试。测试期间保持连接。** 当前图形界面教程使用 USB 连接；单独在电脑上打开 EXE 不会改变手机位置。

[下载最新 EXE](https://github.com/zoe2026test/harmonyos-location-lab/releases/latest) · [反馈问题或建议](https://github.com/zoe2026test/harmonyos-location-lab/issues/new/choose)

## 第一次使用：先准备这些

| 需要准备 | 说明 |
| --- | --- |
| Windows x64 电脑 | EXE 已内置 Python 和界面运行库，不用自己安装 Python |
| 鸿蒙手机 | 需要支持 HDC 和 `testhelper` 位置模拟；USB 能连接不等于一定支持位置模拟 |
| USB 数据线 | 必须能传输数据，只有充电功能的线不行 |
| 本项目 EXE | 到上方下载页选择 `.exe` 文件 |
| 官方 HDC 工具 | 另行获取 `hdc.exe`，并保留同文件夹的 DLL；不包含在本项目 EXE 内 |

历史观察来自一个用户提供版本为 **鸿蒙 7.0.0** 的测试环境，不代表所有同版本设备都兼容。新版界面仅完成无设备测试，仍需真机验证。

## 第 1 步：下载并打开程序

1. 点击 [下载页 Releases](https://github.com/zoe2026test/harmonyos-location-lab/releases/latest)。
2. 找到 **Assets**（下载文件列表），下载名称以 `.exe` 结尾的 Windows x64 文件，例如 `HarmonyOSLocationLab-v0.2.1-win-x64.exe`。
3. 把它放到电脑上的一个文件夹里，双击打开“鸿蒙位置实验室”。首次启动可能稍慢。

`Source code` 是开发者使用的源码，不是普通用户需要运行的程序。EXE 暂未数字签名，同页提供 `SHA256SUMS.txt` 校验值。

## 第 2 步：让程序找到 HDC

HDC 是电脑与鸿蒙手机通信的官方调试工具。**第一次需要准备；之后本程序会记住你选择的 HDC 路径。**

- **电脑上已经有“华为调试工具”或 HDC 文件夹：** 找到其中的 `hdc.exe`，可以直接使用，不必重复安装。不要只移动这个 EXE，把它原文件夹内的 DLL 一起保留。
- **还没有 HDC：** 从 [华为官方开发工具页面](https://developer.huawei.com/consumer/cn/deveco-studio/) 获取 DevEco Studio 或官方 Command Line Tools。安装或解压后，在其 `sdk/default/openharmony/toolchains` 文件夹寻找 `hdc.exe`。实际目录以官方工具安装位置为准。[HDC 官方说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc/)

在“鸿蒙位置实验室”界面点击 **选择 HDC**，找到并选中 `hdc.exe`。本图形界面不要求手动配置 PATH，也不要求输入命令。

## 第 3 步：用数据线连接手机，并完成授权

1. 在手机的 **设置 → 系统 → 开发者选项** 中开启 **USB 调试**。不同系统的菜单名称可能不同，可在设置里搜索“开发者选项”；尚未开启开发者模式时，请按对应系统的官方指导启用。[官方连接指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc/)
2. 用支持数据传输的 **USB 数据线**，把手机连接到运行本程序的这台电脑。
3. 解锁手机。如果出现“USB 连接方式”选项，选择 **传输文件**，不要仅选择充电。
4. 如果手机弹出“是否信任此设备”或调试授权提示，确认是你自己的电脑后，点 **信任／允许**。
5. 回到电脑程序，点击 **检测设备**。
6. 看到设备状态为 **Connected** 才表示调试连接已建立。出现多个设备时，从下拉框选择本次要测试的手机。

**手机显示正在充电、电脑能看见手机文件，都不能代替第 6 步的调试连接确认。**

## 第 4 步：先用默认坐标做短时间测试

1. 选择 **固定位置** 标签页。
2. 第一次可保留默认的埃菲尔铁塔公开示例坐标：纬度 `48.8582599`、经度 `2.2945006`。两项使用 WGS84 坐标，注意不要填反经纬度。
3. 保留 **总时长 60 秒**、**点间隔 1 秒**，点击 **开始测试**。
4. 查看电脑上的状态和日志。看到“系统接受提交”表示调试命令已获系统确认；应用是否实际采用，要在手机上观察。
5. 可在手机微信中打开一个聊天的 **＋ → 位置 → 发送位置**，只查看地图预览，不要点击发送。如果预览已经打开，可先取消，再重新进入让它读取位置。
6. 测试期间保持数据线连接，电脑不要休眠。应用缓存或系统差异可能导致位置不变，不保证每个应用都支持。

默认示例只是便于对照的公开地标，可以自己改成其他有效的 WGS84 坐标。当前界面还没有地图选点或输入地名搜索。

## 第 5 步：停止并确认恢复

1. 点击电脑程序里的 **停止并恢复定位**。到设定时长也会自动尝试结束。
2. 等待状态显示已提交关闭模拟请求，不要直接拔线或强行结束进程。
3. 重新打开手机的位置预览，确认正常定位恢复，再断开数据线。

如果提示关闭模拟未获确认：恢复 USB 连接、重新授权，再点 **停止并恢复定位** 重试，并在手机上确认。断线、电脑休眠或强行结束进程时，程序无法保证自动恢复；必要时在手机上关闭调试并重启定位。

## 想测试一条轨迹怎么办？

先完成上面的连接与固定位置测试，再选择 **GPX 轨迹**：

1. 点击 **导入 GPX**，选择已有的 `.gpx` 轨迹文件。界面默认附有一个公开示例。
2. 设置 **点间隔**，表示每个位置点之间的秒数；**总时长** 是本次会话的上限。
3. 默认到轨迹末尾即结束；需要重复时勾选“到末尾后循环”。
4. 点击 **开始测试**，停止方式与固定位置相同。

轨迹按统一点间隔提交，不按原始 GPX 时间戳或指定速度重新采样。不同轨迹段按文件顺序读取，段间可能跳跃。连续跟随尚未稳定验证；当前也不提供地图绘制路线。

## 常见问题

| 现象 | 应该检查什么 |
| --- | --- |
| 检测不到设备／未发现设备 | 数据线能否传输数据；USB 调试是否开启；手机是否解锁；可换 USB 接口或线后重试 |
| 显示 Unauthorized | 手机尚未授权。解锁查看信任提示；必要时关闭再开启 USB 调试、重新插线后授权，再检测 |
| 电脑能传文件，但仍连不上 | 文件传输与 HDC 调试是两件事，还需要开启 USB 调试并允许这台电脑调试 |
| 找不到 HDC | 点击“选择 HDC”，选官方工具中的 `hdc.exe`；保留其附带 DLL |
| 系统不支持某个命令 | 设备可能未提供该版 `testhelper` 的位置模拟能力；连接成功也不保证功能可用 |
| 已提交位置，但手机应用没变化 | 应用可能使用缓存或其他位置来源。重新进入预览后对照，不将提交成功视为应用兼容 |
| 没有手机或数据线 | 可以打开界面点“仅导出 GPX”，但不会修改任何手机位置 |
| 要不要装 Python／手机 App | EXE 不需要单独安装 Python；本工具不向手机安装 APK/HAP |

## 已观察到什么？

| 测试对象 | 历史原型观察 |
| --- | --- |
| 鸿蒙 7.0.0 测试环境（用户提供版本） | 曾通过 HDC 连接并提交位置，具体系统构建号未记录 |
| 微信“发送位置”地图预览 | 用户多次观察到模拟位置 |
| 校园跑小程序 | 测试失败，不作为项目支持功能 |
| 应用连续跟随 GPX 移动 | 未完成稳定验证 |
| 其他系统与设备 | 未验证 |

以上是历史原型观察，不是当前 EXE 的真机回归结果。工具只报告系统调试结果，不保证应用采用，也不提供隐藏模拟标记或修改第三方应用的功能。
